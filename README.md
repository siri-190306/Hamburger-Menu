#  Responsive Navbar with Hamburger Menu 💜

## Project Description
A modern and responsive navigation bar that automatically adjusts to different screen sizes. On desktop, it displays a horizontal navigation menu, while on mobile devices, it transforms into a hamburger menu with a smooth slide-in animation.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Features
- Responsive navigation bar
- Hamburger menu for mobile screens
- Smooth slide-in and slide-out animation
- Animated hamburger icon
- Interactive navigation links
- CSS media queries
- Escape key support for closing the menu

## What I Learned
- How to create responsive navigation bars.
- How to use CSS media queries.
- How to toggle classes using JavaScript.
- How to create smooth CSS transitions.
- How to handle click and keyboard events.

## Project Structure
- index.html – Website structure
- style.css – Styling and responsive layout
- script.js – Hamburger menu functionality

## How to Run
1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
